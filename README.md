# Практическая работа №1

## Цель
Узнать, как программа на C# получает сведения о компьютере и операционной системе через класс Environment, и сравнить их с тем, что показывает Windows.

## 1. Информация о компьютере
Вывел через Environment.MachineName имя компьютера, через Environment.UserName имя пользователя, через DateTime.Now дату и время. Всё вывелось нормально имя и пользователь совпали с тем что в Параметрах.

## 2. Информация об операционной системе
Вывел OSVersion и Is64BitOperatingSystem. Программа показала 64-битная ОС: True. В Параметрах Windows значения совпадают.

## 3. Логические процессоры
Гипотеза: Environment.ProcessorCount покажет 16.
Программа показала 16. В Диспетчере задач логических процессоров тоже 16. Гипотеза совпала.

## 4. Память процесса
Программа показала 22 МБ (через Environment.WorkingSet). В Диспетчере задач нашёл процесс по PID, там памяти 22 МБ. Числа немного отличаются, потому что Диспетчер считает память чуть по-другому.

## Контрольные вопросы

1. Почему программа может узнать имя компьютера, хотя мы не писали его в коде?
   Потому что она спрашивает его у операционной системы а система это имя знает.

2. Какую роль играет операционная система, когда программа запрашивает у неё сведения?
   ОС как посредник: программа просит, ОС отдаёт данные про компьютер.

3. Что означает «64-битная ОС»?
   Что система работает с 64-разрядными адресами и данными и может использовать больше оперативной памяти чем 32-битная.

4. Что показывает Environment.ProcessorCount и обязательно ли это число совпадает с числом физических ядер?
   Показывает число логических процессоров. Не обязательно совпадает с ядрами из-за Hyper-Threading одно ядро может считаться за два.

5. Чем память процесса (WorkingSet) отличается от всей оперативной памяти компьютера?
   WorkingSet это только память, которую занимает моя программа, а оперативная память это вся память компьютера на всех программах сразу.

6. Почему одна и та же программа без изменений в коде может показать разные результаты на разных компьютерах?
   Потому что она берёт данные с того компьютера где запущена, а у всех разное железо и система.
